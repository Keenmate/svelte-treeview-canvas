INTERACTION
===========

Click behavior, multi-select, drag-drop, clipboard, and context menus.

CLICK BEHAVIOR
---------------
clickBehavior prop controls what happens when clicking a node:

| Mode             | Single click          | Double click         |
|------------------|-----------------------|----------------------|
| select           | Select only           | Expand/collapse      |
| expand           | Expand/collapse       | —                    |
| expand-and-focus | Expand + pan to node  | —                    |

"select" mode is ideal for multi-select workflows (single click = select,
double click = expand).

MULTI-SELECT
-------------
Built-in multi-select interactions:

Ctrl+click (Cmd on Mac):  Toggle node in/out of selection
Shift+click:              Range select (anchor to target)
Shift+drag (empty space): Draw selection rectangle
Ctrl+Shift+drag:          Additive rectangle selection
Plain click:              Clear selection, select one

Props:
  selectedPaths: Set<string>         — Bindable set of selected paths
  rangeSelectionMode: 'visual'|'logical'
    visual:  2D bounding-box from canvas positions (default)
    logical: depth-first tree order (includes collapsed children)
  onSelectionChange: ({ paths, nodes, controller }) => void
  focusedPath: string | null        — Bindable cursor node (keyboard nav / last click)

<CanvasTree
  bind:selectedPaths
  rangeSelectionMode="visual"
  onSelectionChange={({ paths }) => console.log(`${paths.size} selected`)}
  ...
/>

SELECTION RECTANGLE
--------------------
Shift+drag on empty canvas draws a dashed rectangle.
Nodes inside are selected on mouse-up.
Ctrl+Shift+drag adds to existing selection.

Theme tokens: selectionRectFill, selectionRectStroke
CSS variables: --ct-selection-rect-fill, --ct-selection-rect-stroke

DRAG AND DROP
--------------
Canvas-native drag and drop with visual drop zone overlays.

<CanvasTree
  dragDropMode="self"
  onNodeDrop={({ source, target, position }) => {
    // source / target are NodeRefs ({ path, node, parent, siblings }); source is at its new place
    console.log(`Drop ${source.path} ${position} ${target.path}`);
  }}
  ...
/>

Drop positions: 'before' | 'after' | 'child'
Visual indicators colored by theme: dzBefore, dzAfter, dzChild.

CLIPBOARD
----------
isClipboardEnabled={true} activates Ctrl+C/X/V keyboard shortcuts.

Ctrl+C:  Copy selected nodes to clipboard
Ctrl+X:  Cut selected nodes (dimmed at 40% opacity)
Ctrl+V:  Paste under selected node as children
Escape:  Cancel cut (removes dimming)

Props:
  isClipboardEnabled: boolean            — Enable shortcuts (default: false)
  transformDataForPaste: (ctx) => T | null — Transform before paste (ctx.data, ctx.operation, …)
  onNodePaste: (result) => void       — Fired by the tree for every paste (Ctrl+V, menu items, built-in 'paste')

<CanvasTree
  isClipboardEnabled={true}
  transformDataForPaste={({ data, operation }) => ({
    ...data,
    id: crypto.randomUUID(),
    name: operation === 'copy' ? `${data.name} (copy)` : data.name,
  })}
  onNodePaste={(result) => {
    if (result.success) console.log(`Pasted ${result.count} nodes`);
  }}
  ...
/>

Uses TreeEngine clipboard API internally (copyNodes, cutNodes, pasteNodes).

CONTEXT MENUS
--------------
The same entry model as svelte-treeview's <Tree> (core action items). An entry is an item
{ id?, text, icon?, tooltip?, shortcut?, isDisabled?, isVisible?, isDanger?, isToggled?, cssClass?,
  get*Callback(ctx)?, onClick?(detail), children?, getChildrenCallback?(ctx), shouldCloseOnClick? },
a divider (createMenuDivider(text?)) or a built-in action name:
  'copy' 'cut' 'paste' 'delete' 'expand' 'collapse' 'expand-subtree' 'collapse-subtree'
  'expand-all' 'collapse-all' 'sort' 'sort-subtree' 'sort-all'
Built-ins take their text from `labels` and act on the selection when the node is in it, else on
the node. Activation order: beforeActionCallback (false cancels) → item onClick(detail) → built-in
→ onAction(detail). detail = the menu ctx + { action, id, item, source: 'context-menu', … }.

1. Node menu: Right-click a node (multi-selection: read controller.getSelectedNodes())
   getNodeContextMenuItemsCallback: (ctx: TreeMenuContext) => TreeMenuEntry[]
   ctx = { node, path, parent, siblings, controller }

2. Group menu: Right-click a group box
   getGroupContextMenuItemsCallback: (ctx: CanvasGroupMenuContext) => TreeMenuEntry[]
   ctx = TreeMenuContext of the group's parent node + childNodes

3. Canvas menu: Right-click empty space
   getCanvasContextMenuItemsCallback: (ctx: CanvasMenuContext) => (MenuEntry | TreeAction)[]
   ctx = { node: null } + controller (svelte-treeview controller.menuContext(null)) — only the
   node-free built-ins apply: 'paste' (into the root), 'expand-all', 'collapse-all', 'sort-all'
   (node-bound ones show disabled)

import { createMenuDivider } from '@keenmate/svelte-treeview';

<CanvasTree
  getNodeContextMenuItemsCallback={({ node, controller }) => {
    const selected = controller.getSelectedNodes();
    return [
      { text: 'Edit', shortcut: 'F2', onClick: () => editNode(node) },
      'copy', 'cut', 'paste',
      createMenuDivider(),
      { text: 'Delete', isDanger: true, onClick: () => deleteNode(node) },
      ...(selected.length > 1 ? [
        createMenuDivider('Bulk'),
        { text: `Export ${selected.length} nodes`, onClick: () => exportNodes(selected) },
      ] : []),
    ];
  }}
  getCanvasContextMenuItemsCallback={() => [
    { text: 'Zoom to Fit', onClick: () => canvasTreeRef?.zoomToFit() },
    { text: 'Expand All', onClick: () => canvasTreeRef?.expandAll() },
    { text: 'Collapse All', onClick: () => canvasTreeRef?.collapseAll() },
  ]}
  onAction={(detail) => console.log(detail.action, detail.id)}
  ...
/>

Keyboard shortcuts work when menu is open (e.g. pressing "F2" triggers Edit).

FOCUS API
----------
Programmatic viewport control:

canvasTreeRef.focusOnPath('1.2.3', {
  anchor: 'center',        // FocusAnchor
  zoom: 1.0,               // number | 'keep' | 'auto'
  padding: 50,             // px padding around node
  shouldAnimate: true,           // smooth animation
  shouldSelect: true,            // also select the node
});

canvasTreeRef.focusOnNode(node, options);
canvasTreeRef.zoomToFit();

FocusAnchor values:
  'center', 'top-left', 'top-center', 'top-right',
  'center-left', 'center-right',
  'bottom-left', 'bottom-center', 'bottom-right',
  { x: number, y: number }

EXPAND / COLLAPSE
------------------
Same API as svelte-treeview (`paths` = string | string[]; ExpandOptions { isExclusive?, isSilent? }):

await canvasTreeRef.expandNodes('1.2', { isExclusive: true }); // open, collapse everything else
await canvasTreeRef.collapseNodes(['1', '2']);
await canvasTreeRef.toggleNodeExpanded('1.2');                // through beforeExpandCallback
canvasTreeRef.expandAll('1');        // the node + all descendants; no argument = whole tree
canvasTreeRef.collapseAll();
canvasTreeRef.scrollToPath('1.2.3', { shouldExpandAncestors: true });

isSilent = no onNodeExpand / onNodeCollapse / onExpandedChange (the canvas still re-renders).
bind:expandedPaths is the expanded set; assigning it replaces the expanded state (silent).
beforeExpandCallback returning a Promise defers the expand (lazy loading: load children with
ctx.controller.addBranch(...) and resolve).

SORTING
--------
isSortingEnabled={false} keeps the input order. Explicit sorting (runs regardless):
canvasTreeRef.sortNodes('1.2', { direction: 'desc' });   // the node's children, one level
canvasTreeRef.sortAll();                                 // whole tree
With orderMember set, a custom compareCallback / 'desc' rewrites the order values and fires
onNodesSort({ parentPath, nodes, changes }).
